# おつり

現金配達向けのお釣り計算機。黒・白・グレーのダークモードで、Androidの分割画面でも使いやすい表示を目指しています。Expo / React Native / TypeScriptで実装したオフライン対応PWAです。

**公開URL：[https://otsuri.pages.dev/](https://otsuri.pages.dev/)**

## 使い方

1. 商品代金を入力します（起動時の入力対象）。
2. お預かり候補をタップするか、入力先を切り替えてお預かり額を入力します。
3. 自動計算されたお釣りを確認します。不足する場合は不足額を表示します。

入力対象は「お預かり」「商品代金」の2つです。金額は円表記・最大7桁で、お釣りの初期表示は0円です。入力内容は再起動後には保持しません。

| 操作 | 動作 |
| --- | --- |
| 金額欄をタップ | 金額を保持したまま入力先を変更 |
| 入力切替 | 切替先の金額を0円にして入力先を変更 |
| 全クリア | 両方の入力を消去し、商品代金入力に戻す |
| クリア | 入力対象の金額だけを消去 |
| ⌫ | 入力対象の末尾1桁を削除 |
| 候補をタップ | お預かり額に反映し、お預かり入力に切り替え |

## お預かり候補

次の金額を生成し、重複・商品代金未満・7桁を超える候補を除外します。

- 商品代金を5円・10円・100円単位で切り上げた金額（同額は除く）
- 千円単位の切り上げ・5千円・1万円を基準にした金額
- 各基準額に、商品代金の下2桁、またはその5円・10円単位の切り上げ額を加えた金額

同じ千円台の候補を同じ行にまとめ、左から金額順に表示します。候補が少ない場合は空行を残し、4行の表示を維持します。候補内のスクロールやお釣り表示はありません。

商品代金が2,761円の場合：

```text
 2,765   2,770   2,800
 3,000   3,061   3,065   3,070
 5,000   5,061   5,065   5,070
10,000  10,061  10,065  10,070
```

## 画面と分割画面

- 利用可能な高さ100%に追従し、電卓キーは固定高、余った高さは候補の4行に均等配分します。
- 高さ600未満では上部の金額3欄を横並びにします。キーの高さは通常62、コンパクト表示44です（論理ピクセル）。
- 極端に低い画面や文字拡大時は、内容が隠れないよう画面全体をスクロールできます。
- PCブラウザには幅360のプレビューと分割画面確認ボタンを表示します。インストールしたPWAにはプレビュー枠を表示しません。
- Androidネイティブ版はconfig pluginでActivityのリサイズを有効にしています。

## PWAのインストール・オフライン利用

AndroidのChromeで[公開URL](https://otsuri.pages.dev/)をオンラインで開き、読み込み後にメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。電卓アイコンから、ブラウザのアドレスバーがない独立した画面で起動できます。

初回のService Workerによるファイル保存が完了すると、オフラインで起動・計算できます。更新はオンライン時に取得し、保存完了後の次回読み込みから反映します。サイトデータを削除した場合などは、再度オンラインで開く必要があります。

オフライン対応にはHTTPSが必要です。開発用のlocalhostは例外ですが、HTTPのLANアドレスでは利用できません。

## 開発

Node.js 22.13以上（推奨24 LTS）、npmを使用します。

```sh
npm ci
npm run web
```

開発サーバー：http://localhost:8081

PWAのService Workerは本番ビルドにのみ組み込まれます。ローカルでPWAを確認するには以下を実行し、http://localhost:8082 を開きます。

```sh
npm run build:web
python3 -m http.server 8082 --bind 127.0.0.1 --directory dist
```

## 検証

```sh
npm test
npm run typecheck
npm run build:web
npm run test:pwa
```

計算・入力操作・千円台ごとの候補表示をテストします。PWAテストでは生成物とアイコン、およびService Workerの模擬環境でオフライン配信を確認します。ブラウザ実行やAndroid実機でのインストール・機内モード・分割画面のテストを代替するものではありません。

## Cloudflare Pagesへのデプロイ

| 設定 | 値 |
| --- | --- |
| プロジェクト | `otsuri` |
| 本番ブランチ | `main` |
| ビルドコマンド | `npm run build:web` |
| 出力ディレクトリ | `dist` |
| フレームワーク | None |
| 公開URL | https://otsuri.pages.dev/ |

```sh
npx wrangler login
npm run deploy
```

現在はWranglerによる直接アップロードです。GitHubへのpushだけでは自動デプロイされません。`public/_headers`でキャッシュを制御し、Service WorkerはCloudflareで転送される`/index.html`ではなく`/`を保存します。

## ネイティブ版

Android・iOS向けのビルド構成も含みます。Android SDK / Xcodeなどの開発環境が別途必要です。ストア公開は行っていません。

```sh
npm run android
npm run ios
```

## 主なファイル

| ファイル | 内容 |
| --- | --- |
| `App.tsx` | 画面・入力・レスポンシブ表示 |
| `src/calculator.ts` | 計算、入力操作、候補の生成と行分け |
| `src/theme.ts` | ダークモードの配色 |
| `public/manifest.webmanifest` | PWAの名前・アイコン・起動設定 |
| `scripts/build-pwa.mjs` | アイコン生成、HTML調整、キャッシュ対象の生成 |
| `scripts/sw-template.js` | オフライン配信・更新処理 |
| `plugins/withResizableActivity.js` | Androidの分割画面設定 |
